When plan folders contain lots of iterations it can become hard to find information within the files as they are named ITERATION-<number>.md, PLAN-<number>.md or FINDING-001.md

To help with this I want a new command that can be pointed a plan folder and generate a table of contents file name TABLE_OF_CONTENT.md

The file will contain a short, plain English summary of activities at the top followed by a list of files, each with there own 1 line summary of content.

For plans it should also contain a indication if it has been completed or not.

If the table of content file exists then plan, explore and review command must update it after they write the file.
