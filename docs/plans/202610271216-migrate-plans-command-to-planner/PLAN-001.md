# PLAN-001 — Port the `plans` bash script to a Ruby `planner` CLI

Replace `docs/examples/plans` with a Ruby gem that ships a `planner` executable. It has the same
three subcommands (`new`, `plan`, `run`) and copies the script's behaviour exactly. Only the
name changes. The code is laid out so it can be extended later: one class per subcommand in a
registry, and an agent adapter that wraps `claude`. Improvements found along the way go into
`docs/TODO.md`. They are not built in this iteration. Also in scope: RuboCop, a Rakefile, the
README and the glossary.

## Implementation

### Gem scaffolding

- `planner.gemspec`: name `planner`, version `Planner::VERSION`, the author above,
  `required_ruby_version >= 3.4`, `bindir "exe"`, `executables ["planner"]`,
  `files Dir["lib/**/*.rb", "exe/*", "README.md"]` (not `git ls-files`, because the repo
  may not exist yet). Set `metadata["allowed_push_host"] = "https://gems.invalid"` with a
  one-line comment saying it is there to block publishing. Set
  `metadata["rubygems_mfa_required"] = "true"` so the RuboCop gemspec cop passes. No
  runtime dependencies.
- `Gemfile`: `source "https://rubygems.org"`, `gemspec`, then the development gems
  `rake ~> 13.0`, `rspec ~> 3.13`, `rubocop ~> 1.0`, `rubocop-rspec ~> 3.0`,
  `rubocop-rake ~> 0.7`.
- `Rakefile`: `require "bundler/gem_tasks"`, `RSpec::Core::RakeTask.new(:spec)`,
  `RuboCop::RakeTask.new`, `task default: %i[spec rubocop]`.
- `.rubocop.yml`: `plugins: [rubocop-rspec, rubocop-rake]`, `AllCops: TargetRubyVersion: 3.4,
  NewCops: enable, Exclude: [pkg/**/*, docs/**/*]`. Start with the default cops. Only tune
  one if it fights the parity requirement, and if you do, leave a one-line comment saying why.

### Core types

- `Planner::Error < StandardError`: an error the user should see. The CLI prints it as
  `[planner] <message>` and exits 1.
- `Planner::UsageError < Planner::Error`: the CLI prints the usage text and exits 1.
- `Planner::Context = Data.define(:root, :agent, :stdout, :clock)`. `root` is a `Pathname`
  (cwd), `agent` is an agent adapter, `stdout` is an IO, and `clock` is a callable that
  returns a `Time`. Every command gets one, which is how the specs inject fakes.
- `Planner::Slug.call(name)` copies `slugify`. Map `A-Z` to `a-z` (ASCII only, as `tr`
  does), turn each run of `[^a-z0-9]` into one `-`, then strip one leading and one trailing
  `-`.

### Agent adapter (`lib/planner/agents/claude.rb`)

```ruby
class Planner::Agents::Claude
  PLAN_MODEL = "opus"
  DEFAULT_RUN_MODEL = "sonnet"

  def initialize(executor: Kernel.method(:exec)) # injectable for specs
  def plan(iteration_file)   # executor.call("claude", "--model", PLAN_MODEL, "/plan-from-iteration #{iteration_file}")
  def run(prompt, model:)    # executor.call("claude", "--model", model, prompt)
  def default_run_model      # DEFAULT_RUN_MODEL
end
```

Always call `exec` with separate arguments, never a single shell string. This interface
(`plan`, `run`, `default_run_model`) is the contract a future agent must implement. Say so
in the class comment.

### CLI (`lib/planner/cli.rb`)

- `COMMANDS = { "new" => Commands::New, "plan" => Commands::Plan, "run" => Commands::Run }.freeze`.
  To add a subcommand, you add a class and one entry here.
- `USAGE` is the script's usage text with `plans` replaced by `planner`, aligned the same way:
  ```
  usage: planner new <given-name>
         planner plan <iteration-file>
         planner run [--model <model>] <plan-file>
  ```
- `initialize(context:, stderr: $stderr)` and `call(argv)`, which returns an exit status
  (Integer):
  - It takes `argv.first` and looks it up in `COMMANDS`. If it is missing or unknown, it
    raises `UsageError`.
  - It calls `COMMANDS[name].new(context).call(argv.drop(1))` and returns 0.
  - `rescue UsageError`: print `USAGE` to stderr and return 1. `rescue Error => e`: print
    `"[planner] #{e.message}"` to stderr and return 1. The `UsageError` rescue must come first.
- `exe/planner`: `require "planner"`. Build the context with `root: Pathname.pwd`,
  `agent: Planner::Agents::Claude.new`, `stdout: $stdout` and `clock: -> { Time.now }`.
  Then run `exit Planner::CLI.new(context:).call(ARGV)`.

### Commands (each one is `initialize(context)` + `call(args)`)

- **`New`**:
  - `name = args.first`. Raise `UsageError` if it is nil or empty. Extra args are ignored.
  - Run `Slug.call(name)`. If the result is empty, raise
    `Error, "'#{name}' does not contain any usable characters"`.
  - `dir = root/"docs/plans"/"#{clock.call.strftime('%Y%m%d%H%M')}-#{slug}"`. If it already
    exists as a directory, raise `Error, "#{dir} already exists"` (the absolute path, as in
    the script).
  - Run `FileUtils.mkdir_p(dir)`, then print the path relative to root
    (`docs/plans/<stamp>-<slug>`) to stdout.
- **`Plan`**:
  - `file = args.first`. Raise `UsageError` if it is nil or empty. Extra args are ignored.
  - If `File.file?(file)` is false, raise `Error, "#{file} does not exist"`.
  - Call `agent.plan(file)`, passing the path exactly as the user gave it.
- **`Run`**:
  - Set up OptionParser with `-m`, `--model MODEL`, and the model defaulting to
    `agent.default_run_model`.
  - Call `parse!(args)` and rescue `OptionParser::ParseError` as `UsageError`. This covers a
    missing argument and an invalid option.
  - Raise `UsageError` if the model is empty (for example `-m ""`), if more than one
    positional argument is left, or if none is left.
  - If `File.file?(file)` is false, raise `Error, "#{file} does not exist"`.
  - `prompt = File.read(file).sub(/\n+\z/, "")`. This strips trailing newlines the way
    `$(cat file)` does.
  - Call `agent.run(prompt, model:)`.

## Verification

1. `bundle install` succeeds and writes `Gemfile.lock`.
2. `bundle exec rake` passes. That covers all specs and RuboCop with no offences. Spec
   coverage must include:
   - `Slug`: `"Hello World"` gives `hello-world`, `"  --Foo__Bar!! "` gives `foo-bar`,
     `"!!!"` gives an empty string, and non-ASCII input such as `"Café"` gives `caf`.
   - `CLI`: no args, an unknown command, and a `UsageError` each print usage to stderr and
     return 1. An `Error` prints `[planner] …` and returns 1. Success returns 0.
   - `New`: creates `docs/plans/202610271216-hello-world` with a fixed clock and prints the
     relative path. Covers a missing name, an empty slug, and a directory that already
     exists.
   - `Plan`: calls `agent.plan` with the path as given. Covers a missing argument and a
     missing file.
   - `Run`: uses the default model, `-m`, `--model` and `--model=x`. A missing `-m` value,
     `-m ""`, two files, no file, an unknown flag and a missing file each raise the right
     error. Trailing newlines are stripped from the prompt and inner newlines are kept.
   - `Agents::Claude`: with a fake executor, `plan` and `run` pass the exact argv shown above.
   - `exe/planner` (subprocess through `Open3`, `chdir` into a tmp dir, using
     `ruby -I<repo>/lib <repo>/exe/planner`): no args gives exit 1 and usage on stderr;
     `new "Hello World"` gives exit 0, prints `docs/plans/<stamp>-hello-world`, and the
     directory exists; `plan missing.md` gives exit 1 and `[planner] missing.md does not exist`.
3. Check by hand that the output matches the script. In a scratch directory, run
   `docs/examples/plans new "x y"` and `planner new "x y"`, then compare their output and
   exit codes. Do the same with no args and with `plan nope.md`.
4. `bundle exec rake install` succeeds, and `planner` (with no args) prints the usage text
   on your PATH. Launching `claude` through `planner plan` or `planner run` is a manual
   smoke check for you to do. The agent does not do it.
