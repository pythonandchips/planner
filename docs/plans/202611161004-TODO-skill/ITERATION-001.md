Often when prompting we want to keep TODO items what are to be implemented later. We want a skill for agents so that the write the TODO in a agreed format.

The TODO files can be written in the `docs` folder or in the folder for the current file. 
We will call the TODO in the docs folder the global todo and a todo in the plan folder a plan todo.

Todo items must be written in plan english
Todo items must give a short and no more than 3 sentances.
If they come from a specific iteration, review or finding that is to be noted on the todo item
