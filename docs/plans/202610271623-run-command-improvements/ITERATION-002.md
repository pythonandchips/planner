Once a plan has been ran we want to mark it as ran. Add to the run prompt an instruction to mark the plan as completed.

The completed section should be pre-pended to the top of the plan file.
The completion should summarise any commands that it was unable to run unassisted so that permission or instructions can be given to improve the process
Include the elapsed time it took to run the plan in the summary
Include the tokens used/context size that the running the plan consumed
